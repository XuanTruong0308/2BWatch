# 2BShop Application

Tài liệu chính của repository nằm tại:

```text
../README.md
```

File này chỉ giữ vai trò điều hướng nhanh cho thư mục ứng dụng Spring Boot + React.

## Chạy nhanh trong local

Backend:

```powershell
cd D:\BoizShop\2BShop
mvn spring-boot:run
```

Frontend:

```powershell
cd D:\BoizShop\2BShop\frontend
npm install
npm run dev
```

URL sử dụng trong dev:

```text
Storefront: http://localhost:5173
Admin:      http://localhost:5173/admin
Backend:    http://localhost:8080
```

Xem hướng dẫn đầy đủ ở README gốc của repository.
